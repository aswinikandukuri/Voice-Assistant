.

🎤 AI Voice Assistant – Python Internship Project
📌 Project Overview

This project is a real-time AI Voice Assistant built using Python.
It recognizes voice commands offline and performs tasks like telling time, opening websites, and searching Google.

🚀 Technologies Used

Vosk – Offline speech recognition (voice to text)

SoundDevice – Captures microphone audio

pyttsx3 – Converts text to speech

Queue – Handles audio data smoothly

Datetime – Gets current time and date

Webbrowser – Opens Google and YouTube

Time – Manages delays and listening time

▶️ How to Run the Project

Install required libraries:

pip install vosk sounddevice pyttsx3


Download Vosk model and place it in the project folder.

Run the program:

python voice_assist.py


Speak commands like:

“Hello”

“What is the time?”

“Open Google”

“Search Python tutorials”
